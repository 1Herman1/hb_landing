03 / Избранные работы

Портфолио

Смена

SaaS Графики
Подробнее →

Задача

Маленькая сеть кофеен (14 точек) тратила 3 часа на составление графика — через Google Sheets, визуализацию в Excel, согласование по email.

Решение

Сделали веб-сервис: менеджер вводит данные о смене (дата, время, позиции), алгоритм подбирает людей с нужными навыками и свободным временем, проверяет ограничения (макс. часы, дни отдыха). Всё хранится в облаке, доступно с мобильного.

Результат

График за 20 минут вместо 3 часов. Сервис продаётся по подписке конкурентам.

Атлас

Портал Корпоративный
Подробнее →

Задача

Строительный холдинг (800 сотрудников) согласовывал договоры вручную: диспетчер создаёт форму, подрядчик заполняет, юрист проверяет, финансы одобряют. Всё по email и доступу на сервер. Средний срок — 9 дней.

Решение

Портал с чётким workflow: форма → экспорт в Word → визуальный чеклист согласования (кто на каком этапе) → уведомления в email и Telegram.

Результат

Срок согласования — 2 дня. Юристы видят метрики: кто спит на задачах, какие типы договоров тормозят.

Дом Керамики

E-commerce Интеграция
Подробнее →

Задача

12 000 товаров (плитка, керамика), каталог в 1С, нет интернет-магазина. Заказы принимали по телефону. Клиентам нужны фото, цены, расчёт метража для заказа.

Решение

Интернет-магазин на WordPress+WooCommerce с интеграцией 1С (синхронизация каталога, остатков, цен). Специальный калькулятор метража (выбираешь плитку → вводишь размеры → видишь, сколько нужно штук).

Результат

Онлайн-выручка выросла в 2,4 раза за полгода. Тепловые карты показывают, какие плитки популярнее — можно оптимизировать закупки.

Прайм.Фитнес

Мобильное Приложение
Подробнее →

Задача

Сеть фитнес-студий (8 филиалов). Посетители записывались к тренеру по телефону (50% звонков), узнавали расписание через WhatsApp-группы, забывали про тренировки.

Решение

Мобильное приложение: расписание, бронь слота, push-напоминания за день и за час, история посещений, бонусы за регулярность.

Результат

70% записей теперь идёт через приложение вместо звонков. Явка выросла на 12% благодаря напоминаниям.

Поток

ИИ Логистика
Подробнее →

Задача

Логистическая компания получает 400 заявок в день письмами (из разных источников). Диспетчер вручную читает письмо, ищет адрес доставки, вид груза, вес, создаёт запись в CRM, пишет черновик ответа.

Решение

Подключили ИИ (Claude API): письмо с вложениями → ИИ извлекает данные → создаёт сделку в CRM → готовит черновик ответа. Диспетчер только проверяет и отправляет.

Результат

Обработка заявки — 2 минуты вместо 20. Пропускная способность +30% при том же штате. Окупилось за 3 месяца.

Советник

ИИ E-commerce
Подробнее →

Задача

Магазин косметики (3 000 средств). Клиенты не знают, какое средство выбрать: разные типы кожи, назначения, бренды. Служба поддержки — узкое место.

Решение

На сайт встроили чат-бота с ИИ: 4 вопроса о типе кожи и проблемах → персональный набор из каталога → при сложных вопросах переводит на живого консультанта. Бот обучен только на данных магазина.

Результат

Конверсия +18%, средняя покупка +12%, нагрузка на поддержку −40% (они теперь консультируют только сложные случаи).
